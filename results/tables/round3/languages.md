# All 10 languages on FLEURS TEST (public API)

`pronkit.Scorer(lang).score(audio_path, text)` on native FLEURS test speech (correct prompts) and on controlled-error references of the same audio (bench.corrupt: phone_sub_near, phone_sub_far, phone_del, phone_ins, word_swap; 2 errors per utterance; fixed seeds). Controlled errors are a PROXY for learner errors (the audio is native; the reference is wrong), so these AUCs are much higher than on real learner data (see english_vs_azure.md §3). Sound model: English = shipped B, other languages = universal U + the per-language logit bias fitted on FLEURS train. Generated by `python -m bench.eval_languages`.

**Change made after looking at this test set (stated as required):** the first run multiplied the prosody model's tone (zh) / pitch-accent (ja) probabilities into WordResult.prob. It gave native word acceptance 0.374 (zh) and 0.718 (ja) at s = 0.5 and word AUC 0.649 / 0.676. The per-word tone / pitch factor on native speech has median 0.36 (zh) / 0.63 (ja) on this test set and 0.37 / 0.64 on 40 FLEURS-validation clips per language, so the product rejects correctly spoken words. WordResult.prob became the sounds-based probability (tone_prob / stress_prob in their own fields); zh and ja were re-run. In round 2 (§5) a LEARNED combination replaced it where it passed the validation rule (zh, ja, ru). No other language was affected (no stress model was available for en / de / es / it / pt / ru).
