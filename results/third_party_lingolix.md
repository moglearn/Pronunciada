# Pronunciada on the Lingolix pronunciation benchmark (v2026.10)

Generated by `python -m bench.third_party.lingolix all` on 2026-11-18 (Pronunciada 1.0.1). Numbers are in `results/tables/third_party_lingolix.json`.

## The benchmark

Lingolix, one of the vendors it compares, built and published this benchmark: https://github.com/lingolix/pronunciation-benchmark. Its code is MIT. The results post is "Best pronunciation assessment API in 2026? An open benchmark", 11 October 2026: https://lingolix.com/en/blog/best-pronunciation-assessment-api-2026. The post compares Lingolix, Microsoft Azure and TonePerfect. The repository also has a Whisper adapter, but the post reports no Whisper numbers.

- **Test 1:** 200 Common Voice clips per language (en, fr, es, de, ja, ko). 100 clips are controls. In the other 100, one word of the reference text was edited so it no longer matches the audio. For every language except Japanese, 10 of those 100 have no target word that carries the error and are skipped by the metric. Japanese has 40 vowel- or consonant-length edits. The audio is CC0 and comes from the repository's GitHub release (138 MB, no account needed).
- **Test 2:** 500 speechocean762 clips from the **test** split (`build_tier2.py --split test --seed 42`). We checked all 500 IDs and every one is in the test split. A word counts as mispronounced when the human accuracy score is 6/10 or lower. speechocean762 is CC BY 4.0.
- **Metrics:** from `report.py`. AUC is word-level ROC AUC of 1 − word score against the planted or human label. FA@80 is the share of correct words whose error signal is at or above the threshold that catches 80% of the errors. That threshold is set separately for each system, so FA@80 needs no tuned threshold. Test 2 reports Pearson correlation of word score with human word accuracy, and of the system's own sentence score with the human sentence total.

## How Pronunciada was run

We used `Scorer(lang)` with default settings (fp32, strictness 0.5) on the benchmark's audio and `target` text. Each result went through `pronunciada.compat.azure.to_azure`, with the settings the benchmark uses for Azure: Phoneme granularity, miscue on, IPA. It was then reduced exactly as the benchmark's Azure adapter reduces Azure's response:

- word score = AccuracyScore/100
- word flag = ErrorType
- sentence score = PronScore, which is 100 × `scores["total"]`

Nothing was tuned on these items. The benchmark's code was not run. Its metrics were re-implemented from reading `report.py` at tag v2026.10. The test 2 audio is Pronunciada's local lossless copy of the same speechocean762 recordings. All 1,700 requests succeeded.

## Results

Lingolix, Azure and TonePerfect numbers were **published by the benchmark's author, not re-run here**. Pronunciada numbers are from this run, with 95% bootstrap intervals over clips (the benchmark's own procedure).

Test 1, word-level ROC AUC (higher is better):

| | Pronunciada | Lingolix | Azure | TonePerfect |
|---|---|---|---|---|
| en | 0.977 [0.963, 0.988] | 0.97 | 0.94 | 0.84 |
| fr | 0.960 [0.924, 0.987] | 0.96 | 0.91 | 0.80 |
| es | 0.979 [0.970, 0.987] | 0.97 | 0.91 | 0.79 |
| de | 0.940 [0.911, 0.965] | 0.95 | 0.87 | 0.79 |
| ja | 0.846 [0.798, 0.891] | 0.95 | 0.93 | 0.55 |
| ko | 0.912 [0.874, 0.946] | 0.95 | 0.94 | 0.67 |

Test 1, FA@80 (lower is better):

| | Pronunciada | Lingolix | Azure | TonePerfect |
|---|---|---|---|---|
| en | 2.5% [1.0, 3.9] | 1% | 6% | 26% |
| fr | 1.6% [0.9, 3.1] | 1% | 13% | 26% |
| es | 2.4% [1.4, 3.9] | 2% | 14% | 32% |
| de | 6.7% [2.9, 13.1] | 2% | 22% | 42% |
| ja | 20.1% [12.7, 37.4] | 5% | 3% | 74% |
| ko | 8.4% [4.5, 19.3] | 3% | 7% | 56% |

Japanese length errors flagged by the system's own flag: Pronunciada 1 of 40, Lingolix 37, Azure 36, TonePerfect 0. The post does not say how "caught" was counted. For Pronunciada we used its own ErrorType flag. On the length items alone, Pronunciada's AUC is 0.73.

Test 2, Pearson correlation with human judges (speakers bootstrapped for Pronunciada):

| | Pronunciada | Lingolix | Azure | TonePerfect |
|---|---|---|---|---|
| sentence | 0.763 [0.658, 0.832] | 0.74 | 0.76 | 0.59 |
| word | 0.581 [0.489, 0.644] | 0.51 | 0.61 | 0.29 |

With the later `main` rules (commit f8750aa, which drops words that Whisper heard differently from the prompt), test 1 AUC rises by 0.003 to 0.009 in every language. FA@80 falls by 0.4 to 1.6 points.

## Comparability

- The vendors' numbers are the author's, from October 2026, with no API versions and no commit named. They are rounded to two decimals and given without intervals. The post does not say which `report.py` version produced them. This run uses the rules in force on the post's date, and the `main` variant is in the JSON.
- The benchmark's author is a vendor. The post says no test recordings were used to train Lingolix. The README says only that the test 1 sentences were held out from Lingolix training.
- Pronunciada's calibrators were fitted on speechocean762 **train**. All 500 test 2 clips are from the **test** split, so they do not overlap with the calibration data. Pronunciada's own development reported results on this test split in earlier rounds.
- Pronunciada was not fitted on Common Voice. Whether ZIPA's pretraining data includes these clips was not checked.
- The benchmark's latency figures are network round trips from Berlin. Pronunciada runs locally (median 115 ms for a speechocean762 clip on this laptop), so the two are not comparable.
- Japanese words are matched to the benchmark's units by character position. Only 1 of 1,040 Japanese units went unmatched.
