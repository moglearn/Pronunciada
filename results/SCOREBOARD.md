## How to read this

- **Native recordings with altered prompts are not learner speech.** The swap benchmark, planted errors, the contrast audit and the Japanese length rows take native audio and change the text. They show whether a system hears that the audio does not match the text, not how it grades real learners; real mistakes are subtler (English: AUC 0.71–0.72 on real learner errors against 0.98 on the controlled near-swaps).
- **Real-learner evidence exists only for English** (speechocean762, L2-ARCTIC, EpaDB) **and Mandarin** (OMPAL). The other eight languages have no learner corpus with expert marks here.
- **cv-real labels are volunteers' votes**, not expert pronunciation marks: a clip can be rejected for noise, a misread word or a bad microphone. Test B uses self-declared accents.
- **Azure was sent each clip once** (cached responses, Nov 2026, region westus, the locales listed in each results file); its run-to-run variation is not measured. Azure has no per-word stress, no length channel and no per-sound scores outside English, so those rows have no Azure column.
- **Data the system was tuned on**: speechocean762 train, L2-ARCTIC train and EpaDB train (the round-2 word model, see docs/LICENSING.md), FLEURS train / validation, OMPAL dev, cv-real dev. Every row above is on a held-out split. The current Mandarin system's defaults were chosen on OMPAL dev learners, so on OMPAL test it is no longer at first contact; the round-6 column is.
- **Design rounds followed earlier held-out looks.** Rounds 2–18 were each designed after an earlier held-out evaluation had been seen, and each change was selected on separate dev data (train / validation / dev halves) before the held-out sets were run once. The held-out sets have therefore been looked at many times across rounds; small differences should be read with that in mind.
- **Significance**: "significant" = two-sided paired p < 0.05 in the table's own test (or a paired 95 % CI excluding 0 where the table has no p); no correction for the number of comparisons. "Level" = equal at the shown precision.
