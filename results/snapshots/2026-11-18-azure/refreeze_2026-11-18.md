# Re-measurement of the held-out scoreboard, 2026-11-18

The tables behind `SCOREBOARD.md` came from the frozen run of 2026-11-17, which used code 1.0.0
(package fingerprint `c1b348228564a762`). Release 1.0.1 (commit ec36864) replaced scipy's resampler
with a numpy copy. The pitch tracker uses that resampler, so the cached outputs no longer matched the
released code exactly. This run re-scored every held-out set with the code at git HEAD 01a9213
(version 1.0.1, fingerprint `dbbe3ccbd4bcf31e`). Nothing was refitted or re-selected. Azure figures
were read from cached responses only, and every command ran with the Azure credentials removed from
the environment. Machine-readable version: `tables/refreeze_2026-11-18_diff.json`.

## Results

**Azure.** No Azure value moved in any regenerated json table. This covers 2,187 Azure leaves
across the English, swap, cv-real, OMPAL and coaching tables.

**Tally.** 84 comparisons before and after: 40 significantly ahead, 37 not different (20 of them
ahead), 7 significantly behind. No verdict flipped, and no comparison switched between "ahead" and
"behind". The ZIPA-alone tally is also unchanged: 60 rows, 45 ahead, 15 not different, 0 behind.

**SCOREBOARD.md.** Four numbers changed at the printed precision (1,929 numbers before; the new
header adds the dates). Every changed number is a CI bound, a p-value or a hit rate. No point
estimate that is compared with Azure moved.

| section | row | column | old | new |
|---|---|---|---|---|
| Against ZIPA alone, OMPAL | sentence accuracy | Pronunciada CI, lower bound | 0.468 | 0.467 |
| Mandarin, OMPAL test | sentence accuracy | current CI, lower bound | 0.468 | 0.467 |
| Swap benchmark | ru | near AUC, p of ours vs Azure (behind, n.s.) | 0.37 | 0.36 |
| Contrast audit | ru voicing, voiceless → voiced | word hit @ 5 % | 67 % | 68 % |

**Unchanged.** Speechocean762, L2-ARCTIC / EpaDB, int8 and the coaching tables (yardstick, 12b,
round 4) are numerically identical, as is the Japanese length table. The swap, cv-real, OMPAL,
FLEURS-native and contrast-audit tables changed in many json values, by at most 0.008. Only the
rows above changed at printed precision.

**Per-script write-ups.**

- `languages.md`: pt near-AUC CI upper bound 0.978 → 0.979; es stress, one cell 0.838 → 0.839.
- `ompal.md`: the fingerprint, and CI or p cells in the third decimal.
- `cv_real.md`: the generation date, the fingerprint, and "license" → "licence". That last change
  comes from the generator's current text, not from a hand edit.
- `zipa_baseline.md`: the fingerprint and CI bounds (pt near AUC 0.978 → 0.979, ru near AUC
  delta CI +0.076 → +0.075).

**README.md and site/index.html.** No Pronunciada or Azure figure in README "Benchmarks" through
"Compared with ZIPA alone", or on the site, changed at the precision printed there. None of the
four changed scoreboard numbers is quoted in either file. Nothing needs editing to stay consistent.
