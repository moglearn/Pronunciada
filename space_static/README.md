# Pronunciada

On-device pronunciation scoring in 10 languages. An open-source Python library that grades a language learner's speech sound by sound.

- Website: https://pronunciada.dev
- Source: https://github.com/moglearn/pronunciada
- Install: `pip install pronunciada`
